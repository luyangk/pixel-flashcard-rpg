## 第一步：提纲（新增的那一次调用）

**代码里逐字的系统提示词**（`src/app/llmFlow.ts` 的 `OUTLINE_SYSTEM`，节选）：

```
1. 只输出纯文本，不要 JSON、不要 Markdown 代码块、不要解释自己在做什么；
2. 按下面四个小标题分段写，每段 1–6 条，每条一行、以 `- ` 开头：
   【主线】这份资料最想说的是什么（结论、主张、判断标准）；
   【步骤】需要按顺序记住的流程（有几步写几步）；
   【因果】什么条件下会发生什么、为什么；
   【易混】容易记错或搞混的地方（如果有）。
3. 每条 ≤ 40 字，写清楚"道理"本身，**不要**写日期、作者、来源这类元信息；
```

**按这个要求，我手写的提纲（示例）**：

```
【主线】
- 持续学习不必依赖专门的离线阶段
- 局部睡眠（单个回路短暂停摆）也能完成巩固
- 本地规则训练的网路也能做到无离线阶段巩固
【步骤】
- 先用隔离规则约束回放，避免新旧任务互相干扰
- 再让网络在清醒期做穿插式回放
- 最后用局部睡眠窗口做定点巩固
【因果】
- 因为局部睡眠只影响单个回路，所以不必停掉整个训练
- 隔离规则减少了任务间干扰，因此回放的需求随之下降
【易混】
- "离线阶段"≠"暂停训练"：前者是专门的回放期
- 局部睡眠是"逐回路"的，不是全局停机
```

## 第二步：出卡（按骨架生成，`mode:'outline'`）

**新口径的三条关键约束**（`CARD_SYSTEM` 里逐字）：

- `4. front ≤ 60 字，back ≤ 160 字；一张卡可以承载一条链路或多个要点`
- `4b. 优先抽这三类：① 主线结论与判断依据；② 步骤/流程（有序）；③ 因果与条件`
- `4c. 禁止元信息卡：日期、作者、期刊、来源、"本文提出"…一律不做成卡`

**按新口径我手写的卡（示例）**：

| 正面 | 背面 |
|---|---|
| 无离线阶段的持续学习靠什么完成巩固？ | 靠局部睡眠：单个回路短暂停摆期间完成巩固，不必停掉整个训练 |
| 局部睡眠式巩固的三步顺序是什么？ | ① 隔离规则约束回放 → ② 清醒期穿插回放 → ③ 局部睡眠窗口定点巩固 |
| 为什么局部睡眠不必停掉整个训练？ | 因为它只影响**单个回路**，其余回路照常工作（不是全局停机） |
| 隔离规则与回放需求是什么关系？ | 隔离规则减少任务间干扰，因此**回放需求随之下降** |
| 「离线阶段」与「暂停训练」的区别是什么？ | 离线阶段是**专门的回放期**；暂停训练是不学新东西。两者不是一回事 |
