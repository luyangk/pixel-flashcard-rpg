# 知识侠客 · 世界观设定档（LORE）

> 本文是叙事内容的**唯一口径来源**：所有序章、战报、Boss 称号、图鉴彩蛋、二期 LLM 生成文案的提示词都必须与本文一致。
> 玩法机制定义见 `PRD.md`；本文只回答"这个世界是什么样的、为什么这样运转"。
> 版本：v1.0，2026-09-26（grill-me 第二轮共识定稿）。

---

## 1. 时代背景

不远的未来。人类把记忆外包给了云端：搜索引擎替你记事，知识库替你思考，笔记软件替你收藏一切。**没有人再需要记住任何东西——除了大脑里真正长出来的那部分。**

某日开始，野外出现了**混沌**——赛博怪物从数据溢出之地滋生。它们吞掉了云端知识库的全部知识，并且发现了一种猎食方式：**夺走人脑中没有记牢的知识**。被吞噬者不会死，只会茫然——想不起母亲的脸，想不出写过的公式，那些"存过但没背下"的东西永远空了。

云端靠不住的那一天，只有古法记忆里还留着火种。

## 2. 核心法则（与玩法严格同构）

| 世界法则 | 游戏机制 |
|---|---|
| **只有真正记在大脑里的知识才能伤害混沌** | 卡片熟练度（SRS stability/ease）→ 伤害倍率 |
| 记在云端/笔记里但没入脑的知识 = 不存在 | 未复习的新卡伤害趋近于零 |
| 每个知识领域被混沌污染后具象为一头**卷灵** | 卡组 = 领域 = Boss |
| 击败卷灵 = 该领域知识重归人间 | 净化 → 图鉴条目 + 一次性大额经验 |
| 战败不会被夺走已入脑的知识，但会被注入**假记忆** | 失败仅演出篡改版卡面，不改 SRS 数据 |

> ⚠️ 写作红线：任何剧情文案都不得暗示"答错会真的丢卡"或"云端同步可以代替背诵"——前者违背低压基调，后者违背核心法则。

## 3. 主角

**无名侠客**。玩家化身，全程无对白、无性格描写、无背景身世。
- 文本中只以第二人称或"侠客"指代（如"你收剑。混沌又退了一尺。"）。
- 留白是刻意的：侠客的"过去"就是玩家真实背下的每一张卡。
- 明确**不做**：师父向导、同伴角色、多结局人格化 NPC（已评估推迟）。

## 4. 阵营与命名体系

### 4.1 混沌小怪（普通遭遇战）— 赛博意象名
按网络恐怖意象命名，池内轮换：
> 缓存妖 · 爬虫魔 · 弹窗鬼 · 死链尸 · 冗余兽 · 断流魈 · 水群蜃 · 空指针傀 …

小怪没有剧情职能，只负责营造"数据荒原"的氛围。

### 4.2 领域卷灵（Boss）— 「{领域}篇·卷灵」体系
每个知识领域的化身 Boss，命名格式：**「{雅号}篇·卷灵」**。
- 预置四领域官方称号：
  | 卡组（领域） | Boss 称号 | 意象 |
  |---|---|---|
  | 成语典故 | 锦绣篇·卷灵 | 千张成语残页拼成的文蛛 |
  | 英语词根 | 巴别篇·卷灵 | 缠绕语根的断裂方尖碑 |
  | 生活常识 | 烟火篇·卷灵 | 家电坟场里睁开的百万只眼 |
  | 唐诗 | 长安篇·卷灵 | 墨色瀑布倒悬的诗卷巨人 |
- 用户自建领域：默认套模板「{卡组名}·卷灵」；**首次触发 Boss 时询问玩家**：接受默认名 / 自拟称号（≤30 字），LLM 可提供建议名（仅为候选，人工确认）。

### 4.3 场景称谓
战斗背景统称**数据荒原**；藏书阁（图鉴页）是侠客夺回知识的存放地，也是三段暗线文案的阅读处。

## 5. 叙事呈现结构

```
序章（一次性）→ 无尽流遭遇战 × N ─┬→ 每胜一场：战报碎片（1-2句）
                                  ├→ 领域复习达标：卷灵现身 → 净化 → 图鉴彩蛋
                                  └→ 净化 3 / 6 / 9 个领域：暗线三幕
```

### 5.1 序章
- **6–8 屏静态像素插画 + 对话框**，可跳过（跳过后仍可在设置里"重看序章"）。
- 分屏脚本（美术按此出图，每屏一句文言旁白 + 功能按钮保持大白话）：
  1. 【云端盛世】霓虹城市，人人头顶悬浮着发光的数据云。——*"知识不再入脑，云端即是记忆。"*
  2. 【数据溢出】服务器机房窗外，野草从电缆间长出，黑色液体积聚成兽形。——*"荒原之上，混沌睁开第一只眼。"*
  3. 【大遗忘】街头人群呆立，手机滑落；有人抓着头发想不起什么。——*"那日之后，没背进脑子的东西，都没了。"*
  4. 【云端失效】天空中的数据云成片熄灭。——*"云端靠不住了。"*
  5. 【古法】破庙中一卷泛黄的记忆术残谱自动翻页。——*"尚有古法：以脑为库，以记为剑。"*
  6. 【授艺】剪影人物将一张发光的卡片按入胸口。——*"背下来的，才是你的。"*
  7. 【出发】侠客背影走向数据荒原，水墨山脊线上挂着故障感的霓虹月。——*"去吧。夺回人间的知识。"*
  8. （可选收尾）标题画面：《知识侠客》。

### 5.2 战报碎片
- 每场胜利后 1–2 句，从 **约 30 条模板池**随机抽取，抽完重置；可点击跳过。
- 语言规范：半文半白短句，≤30 字，不出现具体卡片内容。示例口吻：
  - *"混沌又退了一尺。"*
  - *"你今日记住的，明日仍在。"*
  - *"荒原的风里有碎掉的问题声。"*
- 其中混入 3–4 条**暗线前奏**碎片（低概率出现，指向"知识的影子"真相）。

### 5.3 三段式开放暗线（净化里程碑驱动）
| 幕 | 触发 | 文案要点（终稿由手写完成，此处为口径） |
|---|---|---|
| 一·源头 | 净化第 3 个领域 | 所有卷灵的残片指向同一个方向——荒原深处有"本体"在收集知识 |
| 二·真相 | 净化第 6 个领域 | 混沌并非入侵者，而是**被云端辜负的知识投下的影子**；它夺记忆，是在"回收" |
| 三·留白 | 净化第 9 个领域 | 侠客立于本体门前——门后是什么，留给二期；结尾一句点题：*"知识不在云上，不在卷上，在你肯不肯再背一遍。"* |
- 每幕 = 1 屏专属插画 + 2–3 句文言战报，进入图鉴"行记"区永久可回看。

### 5.4 图鉴彩蛋（被夺回的知识）
- 每净化一个领域，图鉴条目附一段**彩蛋文案**：该领域的冷知识/名段摘录（纯阅读向，不给数值）。
- 预置 4 领域：手写。自建领域：MVP 即由 LLM 按卡组内容生成（输出视为不可信候选，渲染全量转义，玩家确认后入库）。

### 5.5 假记忆注入（战败演出）
- 卡池耗尽未杀敌 → 战斗界面短暂闪现 1–2 张**篡改版卡面**（答案被改成似是而非的错误内容，红黑色故障特效）→ 随即打叉揭示："假的。幸好你没记住它。"
- **纯演出，零数值后果**：不修改任何 SRS 数据、不冻结计数。重试时敌人保持原样。
- 篡改内容来源：从真答案做规则变换（换数字/换近义反义词），或 LLM 生成后人工抽检；保证"一眼像错的，细想有点慌"的分寸。

## 6. 语言与视觉基调

- **总基调**：新派赛博武侠——末世设定用武侠腔消化，玩梗但不油腻。
- **文案双轨制**：
  - 叙事文本（序章/战报/图鉴/称号）：半文半白，克制、留白、有意境。
  - 功能文本（按钮/表单/帮助/报错）：大白话，绝不为了氛围牺牲可理解性。
- **视觉主轴**：**水墨像素**为底（低饱和、大量留白、宣纸质感噪点），赛博元素（青紫粉高饱和光效、故障闪烁）**只出现在怪物与混沌相关物上**——让"古法 vs 云端"的对抗成为画面上唯一的色彩冲突。
- **音频**：战斗 BGM = 古琴 + 电子氛围铺底；关键音效只做两个：出卡命中、净化成功。

## 7. 名词表（术语锁定）

| 术语 | 定义 | 对应系统概念 |
|---|---|---|
| 混沌 | 赛博怪物的总称 | 敌方单位 |
| 卷灵 | 知识领域被污染后的 Boss 化身 | 领域 Boss |
| 净化 | 击败卷灵 | Boss 战胜利结算 |
| 数据荒原 | 战斗发生的舞台 | 战斗场景 |
| 藏书阁 | 夺回知识的收藏处 | 图鉴一级页 |
| 假记忆 | 混沌注入的篡改知识 | 战败演出 |
| 行记 | 侠客夺回知识的流水账 | 战报/暗线阅读区 |
| 有效复习 | 间隔 ≥1 天的复习（同日重复只计首次） | Boss 触发计数口径 |

## 8. 反过度设计清单（明确不做）

- ❌ 境界/段位等等级换皮命名（等级就叫等级）
- ❌ 固定章节关卡结构（无尽流 + 里程碑暗线替代）
- ❌ 师父/NPC 向导、对话树、多结局
- ❌ 战败的真实惩罚（丢卡、冻结进度）
- ❌ 全局武侠化 UI 术语（心法总纲/纳卷入库之类一律不进功能界面）
