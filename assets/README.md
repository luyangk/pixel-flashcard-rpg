# 素材规格表（assets/）

> 本目录的 PNG 全部由 `scripts/gen-sprites.mjs` 生成，**不要手改 PNG**（改图 = 下次重跑丢失）。
> 契约测试：`tests/assets/assets.contract.test.ts`（存在性 / 尺寸 / 色型 / 调色板 ≤32 / 禁半透明 / 引用完整）。

## 复现方式

```bash
node scripts/gen-sprites.mjs                  # 全量重生成到 assets/sprites/（幂等：逐像素相同）
node scripts/gen-sprites.mjs --check          # 重生成到临时目录并与仓库 PNG 逐字节比对（CI 用）
node scripts/gen-sprites.mjs --only hero,mob-1
node scripts/gen-sprites.mjs --emit-python /tmp/draw.py   # 导出内嵌的绘制程序（审阅/调试）
```

依赖：`python3` + Pillow（本机 10.2.0）与项目级 `pixel-art-studio` skill（脚本自动定位
`scripts/pixelstudio.py`，也可用 `PIXELSTUDIO_SCRIPTS=<skill>/scripts` 指定）。**不联网、不装 npm 包**。
素材是 1x 母版：引擎侧只做整数倍缩放（`src/stage/layout.ts` 的 `fitScale` 已钉死）。

### 背景平铺：三版教训（为什么最后是"安静的碎屑地"）

`bg-arena.png` 在 320×240 舞台上会被平铺 5×3.75 次，任何**≥8px 的可记忆结构**都会变成一眼可辨的重复花纹。
实测三版：① 跨整块的长裂纹 → 重复花纹；② 等长的短斜线 → "鳞片/箭头"底纹，比裂纹更吵；
③ 大块土斑 → 花布，且规则分布读成点阵。定稿 = 低对比颗粒底 + ≤4px 碎屑（覆盖率约 8%）+ 三条 5px 墨痕，
并刻意让部分特征跨界（绘制时全部按 64 取模落点，跨边笔触自动从对边接回来）。
契约侧的对应判据是 `tests/assets/assets.contract.test.ts` 里的"接缝统计"用例（阈值已标定，含假图反证）。

## 美术铁律（PRD §7 / D15 / LORE §6，本目录全部素材遵守）

1. **水墨低饱和为底**：侠客、背景、古法相关画面只用墨/宣纸/赭石；**霓虹（青·品红·电蓝）只出现在
   小怪与卷灵本体**，以及"混沌相关物"（序章二的黑色兽形、序章七的故障月）。
   `bg-arena.png` 刻意一颗霓虹像素都不给——"古法 vs 云端"的色彩冲突必须只发生在怪物身上。
2. **像素精确**：1x 作画、整数缩放导出、无抗锯齿、**无半透明**（所有像素 alpha ∈ {0,255}，契约测试钉死）。
3. **有限调色板**：单张 ≤32 色（实际 8–18 色），手工 ramp（暗部偏冷、亮部偏暖，明度步长 ≥8%）。
4. **选择性轮廓**：外轮廓统一深墨 K0 1px（`outline(where="inside")`）；霓虹核心画在轮廓之上，
   不描边——让"亮"与"墨"在层级上分开。
5. **木桩不是怪物**：`drill-dummy.png` **一颗霓虹都不给**（木桩是练功对象，不是混沌造物）；
   体量取 **32×32（小怪同档）**——练功用遭遇战参数，画成 64×64 会在屏上比小怪大一倍。
6. **无文字**：所有素材不含任何汉字/字形（中文不进入 Canvas）；标题、旁白由 DOM 渲染。
   画面里出现的 1px 短划只是"墨迹/数据行"的示意。
7. **可区分性**：4 款小怪与 4 款卷灵在【轮廓】【核心形状】【光效走向】三处同时区分（详见上表"用途"列）。

## 主屏图标（`assets/icons/`，D51）

装到主屏用的三张 PNG 与游戏素材**同一个生成器家族**，但口径不同（浏览器按 manifest 声明的尺寸取用，
必须是真实像素尺寸）：

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `icon-192.png` | 192×192 | Chrome 的安装判据下限（Lighthouse 口径）；缺它只会得到"书签快捷方式" |
| `icon-512.png` | 512×512 | 启动画面 / 大图标位 |
| `icon-maskable-512.png` | 512×512 | Android 自适应图标（主图缩到 75%，裁圆不掉内容） |

- 原画 **64×64**，由 `pixel-art/app-icon/build.py` 绘制（墨底 + 牌框 + 折角宣纸卡 + 朱砂落款印，
  **不用霓虹**——玩家侧的东西是墨与纸），导出为**整数**放大 ×3 / ×8；
- 重新生成：`python3 pixel-art/app-icon/build.py`；检查仓库产物是否与脚本一致：
  `python3 pixel-art/app-icon/build.py --check`（逐字节比对，与 `gen-sprites.mjs --check` 同款纪律）；
- 构图取舍记录（v1–v5 都用眼睛看过）：剑画在卡后 ⇒ 被卡吃掉只剩两截棍；剑斜压卡上 ⇒ 把卡劈成两半；
  剑横放卡下 ⇒ 三个横条像工具栏。**一个图标只讲一件事**，闪卡是主线物件，剑留给游戏内画面。
